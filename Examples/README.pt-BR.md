# Exemplos fictícios

[English](README.md) | [Início em português](../README.pt-BR.md)

Todos os valores destes CSVs são inventados. EXAMPLE, example.test e os SIDs de exemplo não identificam um cliente. Os arquivos demonstram o formato dos relatórios, não uma auditoria concluída. Não execute o script de riscos com essas identidades esperando encontrar objetos reais no diretório.

Os seis exemplos numerados mostram serviço automático privilegiado em execução (Critical), automático parado (Review), conta local homônima, identidade interna e conta não resolvida. As tarefas separam artefatos interativos de perfil de uma tarefa privilegiada não assistida. A cobertura registra a lacuna de resolução. Sucesso do coletor indica somente conclusão da consulta. Relatórios reais ficam fora de Examples. Veja o [guia dos relatórios](../Docs/Dependency-Reports.pt-BR.md).

Os CSVs mantêm seus nomes, cabeçalhos e valores técnicos em inglês para compatibilidade com os scripts. A explicação de cada relatório está no [README em português](../README.pt-BR.md#relatórios-e-interpretação).
