# Fictitious examples

[Português (Brasil)](README.pt-BR.md)

Every value in these CSVs is fabricated. EXAMPLE, example.test and the sample SIDs do not identify a client. These illustrate the report schemas, not a successful audit. Do not run the risk scanner against these identities expecting real directory objects.

The six numbered examples show a running privileged automatic service (Critical), a stopped automatic service (Review), a same-named local account, a built-in identity and an unresolved account. Scheduled tasks show interactive profile artifacts separately from an unattended privileged task. Coverage records the identity-resolution gap. A successful collector status describes query completion only. Runtime output must remain outside Examples. See the [report guide](../Docs/Dependency-Reports.md).
